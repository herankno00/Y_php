## 技术细节

### 问题根源

**应用层**：
- `apps/common/HomeController.php` 第32-35行：强制HTTPS重定向
- `apps/common/HomeController.php` 第37-47行：强制主域名跳转
- `apps/common/HomeController.php` 第92-101行：手机域名跳转

**系统层**：
- 浏览器缓存301永久重定向（已通过清除缓存解决）

### 解决方案

在三处重定向代码前添加本地环境检测：
```php
if (!$this->isLocalEnvironment()) {
    // 重定向代码
}
```

检测函数识别：localhost, 127.0.0.1, *.local, *.test 等本地域名
