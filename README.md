#### 问题原因

**在 `apps/common/HomeController.php` 中的三处重定向代码：**

1. **强制HTTPS重定向**（第32-35行）
   - 配置项：`to_https`
   - 效果：`http://localhost` → `https://localhost`

2. **强制主域名跳转**（第37-47行）
   - 配置项：`main_domain` + `to_main_domain`
   - 效果：`localhost` → 配置的主域名

3. **手机域名自动跳转**（第92-101行）
   - 配置项：`wap_domain`
   - 效果：移动设备访问时跳转
