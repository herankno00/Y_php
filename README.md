**这说明劫持不是PHP代码引起的，而是系统层面的问题！**

### 🔍 问题诊断

#### 如果IIS已停止但仍跳转 → 系统层面问题

**最可能的原因（90%）**：浏览器缓存了301永久重定向

**快速测试**：
```cmd
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 或使用隐私/无痕模式（Ctrl+Shift+N）
3. 访问 http://localhost
```

**如果清除缓存后不再跳转** → 确认是浏览器缓存问题  
**如果仍然跳转** → 检查hosts文件、DNS设置、浏览器扩展

#### 如果IIS运行时跳转 → PHP代码问题

在 `apps/common/HomeController.php` 中发现的重定向代码：
1. 强制HTTPS重定向（第32-35行）
2. 强制主域名跳转（第37-47行）
3. 手机域名自动跳转（第92-101行）

### 🔧 修复方案

#### 系统层面修复（IIS停止后仍跳转）

```cmd
# 1. 清除浏览器缓存
Ctrl+Shift+Delete

# 2. 清除HSTS缓存（Chrome/Edge）
访问: chrome://net-internals/#hsts
输入: localhost
点击: Delete

# 3. 检查hosts文件（管理员）
notepad C:\Windows\System32\drivers\etc\hosts
确保只有: 127.0.0.1  localhost

# 4. 清除DNS缓存
ipconfig /flushdns
```

#### PHP代码修复（IIS运行时跳转）

编辑配置或修改代码：
```php
'to_https' => 0,         // 关闭强制HTTPS
'to_main_domain' => 0,   // 关闭主域名跳转
```
